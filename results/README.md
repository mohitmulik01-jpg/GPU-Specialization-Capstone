# Execution Results

This directory contains actual output artifacts
generated by executing the CUDA image processing
project on an NVIDIA Tesla T4 GPU using Google Colab.

Files included:
- benchmark.csv: GPU timing measurements
- execution.log: Execution console log
- sample_256_edges.ppm: Processed image
- sample_512_edges.ppm: Processed image
- sample_1024_edges.ppm: Processed image
